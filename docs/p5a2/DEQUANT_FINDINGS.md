# P5a.2 GPU 反量化解包微基准分析报告 (DEQUANT_FINDINGS.md)

## 1. 实验概述

针对真实 OLMoE 专家（`Layer 0 Expert 0`）的 `gate_proj`、`up_proj`、`down_proj` 三矩阵，在 NVIDIA RTX 4060 GPU 上进行了 20 次预热与 100 次计时测试，严格对比旧版 CPU NumPy 解包路径与新版纯 PyTorch CUDA GPU 解包路径。

## 3. 核心性能发现 (Gate G3 判定)

1. **单专家反量化解包耗时剧降**：
   - 旧版 CPU NumPy 路径反量化三个矩阵累计耗时：**27.82 ms**
   - 新版纯 PyTorch CUDA 路径累计耗时：**0.559 ms**
   - **实际测得加速比：49.8 倍！**（门禁 G3: PASS）
2. **零 PCIe 往返开销**：通过矢量化 bitwise 掩码与符号扩展，解包全程在显存内完成，彻底根除了之前每 Token 激活 8 个专家累计带来的 ~200ms CPU 中转瓶颈。
3. **与纯 GEMM 的耗时对比**：当前单矩阵纯 GEMM 耗时约 0.05 ms，GPU 解包耗时降至约 0.19 ms，已与 INT8 反量化（~0.28 ms）处于同一性能量级。
