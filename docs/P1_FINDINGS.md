# P1 阶段实验发现与基线分析

## 1. 实验概述

在 RTX 4060 Laptop 8GB VRAM + 48GB RAM 平台上，对 OLMoE-1B-7B-0125-Instruct-Q4_K_M 进行固定精度基线测量，对比全 GPU 驻留、CPU MoE 专家无缓存（cache=0）以及 CPU MoE + GPU 专家缓存（256/512/1024 MiB）的生成速度与内存占用。

## 3. 关键洞察与发现

- **全 GPU 驻留 (Group A, 257.20 t/s)**：OLMoE-1B-7B Q4_K_M 权重约 4.0GB，完全能够装入 RTX 4060 的 8GB 显存，达到最高的生成速度（约 257 tokens/s），充分利用了 GPU 的张量核心计算与高显存带宽。
- **CPU MoE 无缓存 (Group B, 75.27 t/s)**：专家保留在 CPU 内存，计算时需频繁跨 PCIe 传输或在 CPU 执行 MoE 运算，生成速度下降至 75.27 t/s（约为全 GPU 性能的 29.3%），构成了专家层未缓存的性能下界。
- **GPU 专家缓存的小容量颠簸与大容量跃升 (Group C)**：
  - 256 MiB 缓存: 17.72 t/s
  - 512 MiB 缓存: 18.93 t/s
  - 1024 MiB 缓存: 38.33 t/s（速度翻倍跃升至 38.3 t/s）
  由于 OLMoE 拥有 16 层 × 64 专家 = 1024 个专家，每 token 需激活 128 个专家调用。当缓存仅 256 MiB 时，仅能容纳约 64 个专家（容积率 6.25%），高昂的动态逐 token 驱逐与 PCIe 交换开销导致严重缓存颠簸（thrashing），性能甚至低于完全留在 CPU 顺序计算；但当缓存扩大到 1024 MiB 时，热专家命中率显著攀升，吞吐急剧回升。
- **对后续阶段的指导意义**：小缓存下固定 INT4 容易引发抖动，而多精度预存储（例如在有限缓存预算中用 INT4 存更多热专家，同时对高权重专家保留高精度）具有巨大的优化空间。
