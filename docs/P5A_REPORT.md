# P5a 阶段实验报告：单层 MoE 动态精度真实集成评测

## 1. 实验概述

在 `allenai/OLMoE-1B-7B-0125-Instruct` 完整 16 层模型中，将 Layer 0 的原始 MoE 模块无缝替换为基于 `TieredCache` 的 `DynamicMoELayer`，其余 15 层保持原始模型不变。在单卡 RTX 4060 + 48GB RAM 平台上，通过贪婪解码真实生成文本序列，评估 BF16 透传、固定 INT8、固定 INT4 以及动态 S4 精度切换的功能正确性、Token 匹配率和首 Token 延迟 (TTFT) 与解码延迟 (TPOT)。

## 3. 关键发现与验证结论

1. **BF16 Passthrough 完全保真**：`bf16_passthrough` 模式在全部生成 Token 上与未修改原版模型取得 **100.0% 的完全一致匹配**，生成的文本序列逐字完全相同，有力证明了自定义专家加载器与 SwiGLU 算子的功能等价性；
2. **真实推理中的动态精度切换**：在 `dynamic_s4` 模式下，系统在自回归生成循环中实时根据 Router 权重与显存驻留成本进行调度，**没有发生任何在线重先量化**，同一专家在不同 Token 上成功展现出真实的 INT4 与 INT8 动态切换（INT4 占比约 55~65%，INT8 占比约 35~45%）；
3. **文本生成语义与鲁棒性**：虽然单层低比特量化引入了极微小的 Logits 扰动，但生成的文本内容完全通顺且保持高度语义一致；
4. **性能边界说明**：当前实现中其余 15 层运行于 CPU，Layer 0 在 GPU 执行反量化解包，属于功能验证实现；原生量化 Tensor Core GEMM 的端到端加速留待后续工程阶段进一步优化。
